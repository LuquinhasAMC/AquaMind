## AquaMind

O AquaMind foi desenvolvido para um evento escolar em 2025, mas eu o mantenho atualizado para quem quiser usa-lo ou modifica-lo.

## O que ele faz?

O AquaMind serve para apresentar curiosidades e informações gerais sobre o mundo aquiático utilizando IA para gerar respostas variadas.

## Quais dependências o projeto tem?

A principal dependência do projeto é a API da IA que é fornecida pela [pollnations.ai](https://pollinations.ai.)

## Como modificar e criar um novo projeto a partir deste?

Se você gostou do projeto e quer fazer a sua versão com melhorias ou novos conteúdos utilizando como base o código deste repositório, saiba que você está liberado para fazer isso, tudo o que você precisa fazer é baixar o código e começar a editar, este projeto não usa node, tudo é feito em HTML, CSS e JS padrão.
